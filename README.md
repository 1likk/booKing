# 📚 Booking Project - Интернет-магазин книг

Современный веб-проект интернет-магазина книг с элегантным дизайном и удобным интерфейсом.

## 🎨 Особенности дизайна

- **Стильные карточки товаров** с декоративными элементами
- **Адаптивная корзина** с красивым фоновым орнаментом
- **Плавные анимации** и эффекты наведения
- **Современный UI** с закругленными углами и тенями
- **Цветовая схема** в коричнево-бежевых тонах

## 🛠️ Технологии

- **Backend**: Django
- **Frontend**: HTML, CSS, JavaScript
- **База данных**: SQLite/PostgreSQL
- **Стилизация**: Custom CSS с продуманной типографикой

## 📦 Основные функции

### Каталог товаров
- Отображение книг с изображениями и описаниями
- Фильтрация по категориям
- Пагинация для удобной навигации
- Система скидок с перечеркнутой старой ценой

### Корзина покупок
- Добавление/удаление товаров
- Изменение количества товаров
- Подсчет общей суммы заказа
- Красивые карточки товаров с декоративным орнаментом
- Индикатор количества товаров

### Интерфейс
- Боковое меню с категориями книг
- Активное выделение выбранной категории
- Адаптивные кнопки с эффектами
- Стильные формы ввода
